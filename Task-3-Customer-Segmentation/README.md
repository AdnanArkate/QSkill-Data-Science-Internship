# Customer Segmentation Using Data Analysis & Clustering

## QSkill Data Science Internship – Task 3

This project focuses on analyzing customer purchasing behavior and grouping customers into different segments based on their purchasing patterns.

## Dataset

The dataset used in this project is the Online Retail dataset.

It contains information about:

* Invoice Number
* Stock Code
* Product Description
* Quantity
* Invoice Date
* Unit Price
* Customer ID
* Country

The dataset is used to calculate RFM values and perform customer segmentation.

## Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab / Jupyter Notebook

## Work Done

The following analysis was performed:

1. Loaded and explored the retail transaction dataset.
2. Checked for missing values and duplicate records.
3. Cleaned the transaction data.
4. Removed cancelled orders and invalid transactions.
5. Calculated total transaction amounts.
6. Analyzed basic sales information.
7. Studied monthly sales trends.
8. Performed RFM analysis using Recency, Frequency and Monetary values.
9. Visualized customer RFM characteristics.
10. Prepared the RFM data for clustering.
11. Used the Elbow Method to examine the number of clusters.
12. Applied K-Means clustering.
13. Evaluated the clustering using Silhouette Score.
14. Analyzed the different customer segments.
15. Created business recommendations for the customer segments.

## Visualizations

The project includes:

* Monthly sales trend
