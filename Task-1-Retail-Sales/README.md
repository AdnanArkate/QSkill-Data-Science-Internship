# Retail Sales Data Analysis & Business Insights

# QSkill Data Science Internship – Task 1

This project is based on retail sales data. The main aim of this task is to clean and analyze the dataset, understand sales and profit patterns, and find useful business insights from the data.

# Dataset

The dataset used in this project is the Sample Superstore dataset.

It contains information about:

* Orders and order dates
* Customers
* Products
* Categories
* Regions
* Sales
* Quantity
* Discount
* Profit

Dataset file used in this project:

`superstore.csv`

# Tools and Libraries Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab / Jupyter Notebook

# Work Done

The following analysis was performed:

1. Loaded the retail sales dataset using Pandas.
2. Checked the structure and data types of the dataset.
3. Checked for missing values and duplicate records.
4. Cleaned the dataset.
5. Calculated basic sales, profit, quantity, customer and order statistics.
6. Analyzed sales by category.
7. Studied monthly sales trends.
8. Analyzed the relationship between sales and profit.
9. Created a correlation heatmap.
10. Found the top products based on sales.
11. Analyzed regional performance.
12. Identified top customers.
13. Compared profit across different categories.
14. Identified important trends and business insights.

# Visualizations

The project includes:

* Bar charts
* Line charts
* Scatter plots
* Correlation heatmap
