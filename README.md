# Student Performance Analysis & Prediction

## QSkill Data Science Internship – Task 2

This project focuses on analyzing student performance and understanding the factors that can affect exam scores. A machine learning model is also used to predict student exam scores.

## Dataset

The dataset used in this project is the Student Performance Factors dataset.

It contains information about:

* Hours Studied
* Attendance
* Previous Scores
* Parental Education Level
* Internet Access
* Extracurricular Activities
* Exam Score
* Other student-related factors

Dataset file used in this project:

`StudentPerformanceFactors.csv`

## Tools and Libraries Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab / Jupyter Notebook

## Work Done

The following analysis was performed:

1. Loaded and explored the student performance dataset.
2. Checked the structure and data types of the dataset.
3. Checked for missing values and duplicate records.
4. Cleaned the dataset.
5. Calculated basic statistics.
6. Analyzed study hours and exam scores.
7. Analyzed attendance and exam scores.
8. Studied the effect of previous scores.
9. Analyzed parental education level.
10. Analyzed internet access and extracurricular activities.
11. Created visualizations and a correlation heatmap.
12. Prepared the data for machine learning.
13. Built a Linear Regression model to predict Exam Score.
14. Evaluated the model using MAE, RMSE and R2 Score.
15. Compared actual and predicted exam scores.
16. Identified important observations from the analysis.

## Visualizations

The project includes:

* Scatter plots
* Box plots
* Correlation heatmap
* Actual vs Predicted score plot
