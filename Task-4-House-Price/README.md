# House Price Analysis & Prediction

## QSkill Data Science Internship – Task 4

This project focuses on analyzing house prices, understanding the factors affecting house prices, and building a machine learning model to predict house sale prices.

## Dataset

The dataset used in this project is the House Prices dataset.

It contains information about:

* House quality
* Living area
* Number of bedrooms
* Number of bathrooms
* Year built
* Garage information
* Location and other house features
* Sale Price

The SalePrice column is used as the target variable for prediction.

## Tools and Libraries Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Google Colab / Jupyter Notebook

## Work Done

1. Loaded and explored the house price dataset.
2. Checked the dataset structure and basic statistics.
3. Checked for missing values and duplicate records.
4. Cleaned the dataset by handling missing values.
5. Removed columns with a large amount of missing data.
6. Checked and handled duplicate records.
7. Performed exploratory data analysis.
8. Analyzed the relationship between living area and sale price.
9. Analyzed house quality and sale price.
10. Studied the relationship between year built and sale price.
11. Performed correlation analysis.
12. Created a correlation heatmap.
13. Converted categorical data into numerical form.
14. Selected important features for analysis.
15. Divided the data into training and testing sets.
16. Built a Linear Regression model.
17. Predicted house sale prices.
18. Evaluated the model using MAE, RMSE and R2 Score.
19. Compared actual and predicted house prices.

## Visualizations
